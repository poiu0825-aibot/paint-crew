# 漆地爭霸 · Paint Crew

工人漆地主題的 2–4 人網頁桌遊。桌機與手機直向皆可玩。

## 執行

需要 Node.js 22 或更新版本。

```sh
npm ci
npm run build
npm start
```

瀏覽 `http://localhost:3100`。開發時同時執行 `npm start` 與 `npm run dev`，Vite 會代理即時連線。

```sh
npm test
```

## 遊戲流程

- 建立工地、分享六碼房號或邀請連結；選擇不重複鋼盔顏色並準備。
- 房主可加電腦陪玩，所有人準備後開始。
- 每人有獨立棋子，從中央周圍的不同位置開始。每回合只移動自己的工人，先選左轉、直走或右轉，再擲 1 / 2 / 2 / 3 / 3 / 4 步骰。
- 踩到對手的同色連通漆地，每個連通格付 1 元；斜角不連通。
- 點兩個相鄰格預覽 2×1 油漆，確認後才落地。至少一格貼著自己的棋子，不能刷任何工人腳下；工人可同格停留；不能一次完整蓋掉同一塊對手油漆。
- 每人油漆固定為鋼盔顏色。2 人各 24 桶，3 人各 15 桶，4 人各 12 桶；每人起始餘額 30 元。
- 工程款耗盡退出施工；已有油漆留作中立地。
- 油漆用完或只剩一位未破產工人，按工程款 + 可見格數結算；同分比工程款，再同分並列。
- 所有在線真人按「再來一局」後回到大廳，重新準備。

## 連線與部署

Node + Express + Socket.IO 作為單一權威伺服器；React + Vite 前端。每個房間有獨立狀態與聊天室；骰子、回合、刷漆、費用與計分均在伺服器驗證。客戶端不會收到他人回座憑證或未來的油漆牌序。

Render 使用 `render.yaml`：`npm ci && npm run build`，啟動 `npm start`。健康端點 `/api/health`。

此試玩版的房間與對話暫存在伺服器記憶體。一般網路斷線或頁面重新整理，可在原分頁回到原座位；伺服器重新部署、重啟、免費服務休眠後重啟會清空房間。使用單一執行個體，尚未串接永久資料庫或跨執行個體同步。離線超過 20 秒可由房主請電腦接手，該座位即轉為電腦。

免費服務的冷啟動可能需要等待。不要在遊戲進行中部署新版本。聊天室只用於房間內臨時對話，不提供歷史存檔。

## 驗證

- 360 場有種子亂數的完整對局：供給、金額守恆、合法落點、結束條件、計分。
- 規則單元測試：棋盤邊界往返、同色四向連通、覆蓋限制、破產中立化、禁止越權與重複行動。
- 真實 Socket 整合：雙人加入、選色衝突、房主權限、對話、完整對局、回座、滿房、再一局。
- 本機桌面與 390px 手機直向瀏覽器：建立房間、選色、準備、擲骰、點格、確認刷漆與電腦回合。

## 後續干擾機制候選（尚未加入）

1. 施工圍籬：短暫封住一個空格，不能放在工人腳下，並須保留合法刷漆位置。
2. 快乾漆：保護一塊自己的漆一輪，每位玩家限用一次。
3. 加班指令：一次重新擲骰，必須接受新結果；可設為消耗工程款。

先試玩基本版，再決定是否採用，避免影響目前規則與平衡。

## v1.1.0 調整

- 玩家各自擁有位置與朝向，其他玩家移動不會改變自己的棋子。
- 包含雙人局在內，每位玩家始終只有一種油漆顏色。
- 房號有內容時禁止建立工地；邀請連結會帶入房號，可清空後改為建立。
- 金額使用元，付款列明付款方、收款方與實際金額。
